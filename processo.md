# Processo de Refatoração

1. **Fork** do repositório original para nossa equipe.
2. **Branch** `feature/refactor-knapsack` criada para isolar alterações.
3. **Commits atômicos**, seguindo convenção (tipo:descrição).
4. **Pull Request** aberto para revisão antes do merge.
5. **Uso de tags**: `v1.0-original` e `v1.1-refatorado`.
6. **Ferramentas**: pytest, flake8, pylint, SonarQube (report gerado em `reports/sonar/`).
